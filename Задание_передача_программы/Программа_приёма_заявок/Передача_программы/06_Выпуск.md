# Выпуск доступ и возврат

Проект: Приём заявок
Версия: 0.3.1

## Версия и условие выпуска
Выпускаемая версия: 0.3.1. Условие готовности к выпуску: успешное прохождение граничного теста лимита (T-01), теста полного сброса (T-02), регрессионных проверок (T-03, T-04) и наличие согласованного комплекта файлов с инструкцией.

## Копия до начала
Перед внесением изменений и сборкой релиза исходные файлы app.py (версии 0.3.0) и logo.png скопированы в отдельную резервную папку Исходная_0_3_0.

## Проверка восстановления
Выполнен тестовый запуск резервной копии из папки Исходная_0_3_0: окно «Приём заявок 0.3.0» открылось с логотипом, приём одной заявки отработал корректно. Резервная копия работоспособна.

## Права пользователя
Обычному пользователю (оператору) доступны все элементы графического интерфейса окна: кнопки «Принять заявку», «Сменить статус» и «Сбросить». Отдельная учётная запись или авторизация в программе не предусмотрены.

## Права администратора
Участник сопровождения/поддержки (Ананьев Александр, 12ТЭС) выполняет развёртывание файлов комплекта, проверку наличия Python 3 с Tkinter и восстановление файлов при сбое. Встроенного разграничения прав администратора и оператора в коде нет.

## Порядок установки
1. Закрыть окно предыдущей версии программы 0.3.0.
2. Поместить согласованные файлы app.py (версии 0.3.1) и logo.png в одну рабочую папку Комплект_0_3_1 вместе с документацией и README.md.
3. Запустить программу из терминала командой python app.py (на Windows при необходимости py app.py, на Mac/Linux — python3 app.py).

## Проверка после выпуска
Непосредственно из папки Комплект_0_3_1 выполнен контрольный запуск: проверены заголовок «Приём заявок 0.3.1», приём 1 заявки с датой, блокировка на 10-й заявке («Лимит: 10»), круг статусов и полный сброс всех счётчиков в исходное состояние.

## Возврат при неудаче
В случае сбоя новой версии необходимо закрыть окно 0.3.1, перейти в резервную папку Исходная_0_3_0 и запустить согласованную исходную копию app.py + logo.png. После запуска счётчики начнутся с нуля (состояние на диске программа не хранит).

## Ограничение
В программе отсутствуют: сохранение счётчиков на диск после закрытия окна, хранение списка отдельных заявок, база данных, авторизация и программное разграничение прав доступа.
