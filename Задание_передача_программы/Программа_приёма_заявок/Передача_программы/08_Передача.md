# Передача инструкция и выводы

Проект: Приём заявок
Версия: 0.3.1

## Комплект и версия
Передаваемый комплект (папка Комплект_0_3_1, версия 0.3.1): исправленный скрипт app.py (0.3.1), обязательный файл изображения logo.png, инструкция получателя README.md и папка документации Передача_программы (файлы 00–08).

## Шаги инструкции
1. Полностью распаковать папку Комплект_0_3_1.
2. Открыть папку Комплект_0_3_1 в VS Code (File → Open Folder…).
3. Открыть встроенный терминал (Terminal → New Terminal) в этой папке.
4. Выполнить запуск: python app.py (на Windows при необходимости py app.py, на Mac/Linux — python3 app.py).

## Результат и помощь
Ожидаемый результат: открывается окно «Приём заявок 0.3.1» с логотипом и нулевыми счётчиками. Помощь при ошибках: проверить наличие Python 3 с Tkinter и файла logo.png рядом с app.py; при сохранении проблемы обратиться к Ананьеву Александру (группа 12ТЭС, учебный чат) с текстом ошибки из терминала.

## Показ
Краткий демонстрационный сценарий при передаче: запустить 0.3.1 → принять 1 заявку (показать счётчик 1 и дату) → довести до 10 заявок (показать «Лимит: 10» и блокировку кнопки) → дважды сменить статус (показать «Готово» и закрыто 1) → нажать «Сбросить» (показать полный возврат к 0, «—», «Новая», 0).

## Приёмка
Решение: принять выпуск 0.3.1 к передаче. Критерии приёмки (лимит 10, полный сброс, регрессия и независимый запуск из Комплект_0_3_1) полностью подтверждены результатами тестов T-01 — T-04.

## Ограничения
Программа не сохраняет данные и счётчики после закрытия окна, не ведёт список отдельных заявок, не использует базу данных и не имеет системы авторизации или разграничения прав.
